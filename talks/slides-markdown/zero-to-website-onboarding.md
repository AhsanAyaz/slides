### Chapters 1-3: Foundations 🏗️

* **Chapter 1: HTML5** — Document structure, forms, tables, and semantic markup.
* **Chapter 2: CSS3** — Selectors, box model, colors, layouts, and typography.
* **Chapter 3: CSS Advances** — Flexbox, CSS Grid, animations, and responsive web design.

--

### Chapters 4-5: JavaScript ⚡

* **Chapter 4: JavaScript Basics** — Syntax, DOM manipulation, variables, loops, arrays, and events.
* **Chapter 5: Advanced JS** — Promises, fetch API, asynchronous programming, and modern ES6+ features.

--

### Chapters 6-7: Portfolio Projects 🎨

* **Chapter 6: Developer Portfolio** — Designing, building, and structuring your personal developer showcase.
* **Chapter 7: Interactive App** — Coding a live interactive JavaScript web application to prove your skills.
