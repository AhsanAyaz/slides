# Phase 1 — UI Design Contract: Deck Shell & Style Foundation

> Visual and interaction contract for the TEDx KTH shell and style foundation.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

**Scope:** Wire `talks/tedx-kth.html`, load plugins and fonts, publish CSS custom-property
contract in `talks/tedx-kth/style.css`. Deck opens to a styled-but-empty frame with two
palette-probe placeholder sections. No per-slide layouts; no hub registration.

## Spacing Scale

Declared values (multiples of 4). This phase uses CSS directly — map tokens to inline values
in `talks/tedx-kth/style.css`. Reveal.js percentages (e.g. `padding: 7% 9%`) used for
slide-canvas padding so slides scale correctly at any viewport; pixel values apply to
decorative micro-spacing.

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px | Inline gaps (browser-dot gap, badge padding) |
| sm | 8px | Intra-element spacing (eyebrow margin-bottom, badge side padding) |
| md | 16px | Section padding, notes border offset |
| lg | 24px | Between major content blocks on probe slides |
| xl | 32px | — (reserved; not required in shell phase) |
| 2xl | 48px | — (reserved; not required in shell phase) |
| 3xl | 64px | — (reserved; not required in shell phase) |

**Exceptions:**
- Slide-canvas padding uses viewport-relative units (`7% 9%`) to maintain 16:9 scaling at
  1920×1080 projector resolution — these are not overriding the pixel scale, they live at a
  different layer (slide content vs. UI chrome).
- Accent rule/bar decorations: `width: 40px; height: 4px` — hard-coded to match mockup
  geometry exactly (not derived from the spacing scale).

## Typography

This phase establishes the CSS custom-property font stacks and weights that all later slides
consume. The values below are the exact sizes used in the mockup's global rules and probe
slides. Phase 2 introduces per-slide overrides using the same stack variables.

| Role | Font stack variable | Size | Weight | Line Height | Letter Spacing | Source |
|------|--------------------|----- |--------|-------------|----------------|--------|
| Eyebrow / label | `var(--mono)` — JetBrains Mono | `clamp(9px, 1vw, 12px)` | 400 | 1.4 | 0.15–0.30em (uppercase) | mockup slide-1, slide-label |
| Body / meta | `var(--sans)` — Inter | 14px | 400 | 1.6 | normal | mockup `.slide-notes` |
| Sub-heading / definition label | `var(--mono)` — JetBrains Mono | 11–12px | 400–500 | 1.4 | 0.05–0.15em | mockup `.deck-meta`, `.slide-label` |
| Heading / title | `var(--serif)` — Fraunces | `clamp(22px, 3.4vw, 46px)` | 400 (title-1) / 600 italic (title-2) | 1.15 | -0.02em | mockup slide-1 `.title-1`/`.title-2` |
| Display / stat | `var(--serif)` — Fraunces | Large (Phase 2 defines per-slide) | 400–600 | 1.1 | -0.02em | mockup slide-7, slide-8 |

**Summary for Phase 1 shell:** Declare exactly 3 font-stack CSS variables (`--serif`, `--mono`,
`--sans`). Phase 1 does not prescribe display-size pixel values beyond the probe sections
— those lock in Phase 2.

**Probe-section typography contract (must exercise all three stacks):**

- Fraunces 500 at `clamp(22px, 3.4vw, 46px)`, line-height 1.15, letter-spacing -0.02em —
  one headline on each probe section.
- JetBrains Mono 400 at `clamp(9px, 1vw, 12px)`, letter-spacing 0.3em, text-transform
  uppercase — one eyebrow line on each probe section.
- Inter 400 at 14px, line-height 1.5 — one body line on each probe section.
- One element per probe section must display `--accent` (`#e62b1e`) so the color loads and
  renders visibly.

## Color

### CSS Custom-Property Contract

Copy the following block verbatim into `talks/tedx-kth/style.css` under `body.tedx`
(lifted from `talks/tedx-kth/reference-material/slides.html` lines 11–25):

```css
body.tedx {
  --bg-deep:        #0a0a0a;
  --bg-soft:        #f5f1ea;
  --ink:            #f5f1ea;
  --ink-soft:       rgba(245, 241, 234, 0.6);
  --ink-faint:      rgba(245, 241, 234, 0.25);
  --ink-dark:       #0a0a0a;
  --ink-dark-soft:  rgba(10, 10, 10, 0.55);
  --accent:         #e62b1e;
  --accent-soft:    rgba(230, 43, 30, 0.15);
  --gold:           #c9a961;
  --serif:          'Fraunces', Georgia, serif;
  --mono:           'JetBrains Mono', 'Courier New', monospace;
  --sans:           'Inter', sans-serif;
}
```

These variable names are canonical — Phase 2 lifts mockup CSS blocks verbatim using them.
Do not rename any variable.

### 60 / 30 / 10 Color Split

| Role | Value | Usage | Source |
|------|-------|-------|--------|
| Dominant (60%) — deep | `#0a0a0a` (`--bg-deep`) | Default slide canvas background (8 of 12 slides); `<body>` background during deck load | STYLE-02, D-11 |
| Secondary (30%) — cream | `#f5f1ea` (`--bg-soft`) | Cream-palette slide canvas (slides 6, 10, 12); also `--ink` on deep-palette slides | STYLE-02, D-10 |
| Accent (10%) | `#e62b1e` (`--accent`) | See reserved-for list below | STYLE-01 |
| Secondary accent | `#c9a961` (`--gold`) | Terminal `$` prompt on slide 4; icon accent on 2×2 AI-grid slide | mockup |
| Destructive | none | No destructive actions in this phase | — |

**Accent `#e62b1e` reserved for (Phase 1 scope — probe sections only):**
- One decorative rule/bar element per probe section (confirms accent renders)
- The TEDx-red accent bar `::before` pseudo-element on the title-slide clone in the deep probe
- Italic `color: var(--accent)` on one text element per probe section

**Accent use is strictly prohibited on:** borders, backgrounds (except `--accent-soft` tint),
interactive states, hover effects, or any element the mockup renders in `--ink`, `--gold`,
or neutral grays.

### Ink Color Switching (Two-Palette Mechanism)

| Palette class | Background | `--ink` override | `--ink-soft` override |
|---------------|-----------|------------------|-----------------------|
| `.deep` (default) | `data-background-color="#0a0a0a"` | `#f5f1ea` (light on dark) | `rgba(245,241,234,0.6)` |
| `.cream` | `data-background-color="#f5f1ea"` | `#1a1208` (dark on light) | `rgba(26,18,8,0.55)` |

The `.deep` class is **implicit** — a `<section>` without a class renders dark. The `.cream`
class must be explicitly set on cream-background sections (D-11).

## Interaction Contract

Phase 1 has no interactive components beyond Reveal.js defaults. The following interactions
must work at phase-end verification:

| Interaction | Expected result | Required by |
|-------------|----------------|-------------|
| Open `talks/tedx-kth.html` in browser | Deck loads, shows deep-palette probe slide, zero console errors | Phase 1 success criterion 1 |
| Right-arrow / space | Advances from deep probe section to cream probe section | DECK-01, DECK-04 |
| `s` key | Notes window opens (RevealNotes plugin active — notes can be empty at this stage) | DECK-04 |
| Resize window | Slide canvas rescales; typography does not overflow or collapse | Reveal.js default behavior |
| Load with Google Fonts blocked | Deck still displays probe sections in system-font fallbacks (Georgia / Courier New / system-ui); layout does not collapse | D-04, D-06, VERIFY-04 foundation |

No hover states, focus rings, keyboard traps, modals, or scroll interactions are introduced in
this phase.

## CSS Counter-Rules (Required)

The following rules must exist in `talks/tedx-kth/style.css` to neutralize global
`css/customizations.scss` rules without modifying the shared file (D-03):

```css
/* Counter: customizations.scss sets .reveal code:not(.hljs) { color: yellow } */
body.tedx .reveal code:not(.hljs) {
  color: var(--ink);
}

/* Counter: customizations.scss sets .reveal .slides { font-size: 32px } */
body.tedx .reveal .slides {
  font-size: unset;
}
```
